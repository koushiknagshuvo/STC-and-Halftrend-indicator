# Trading Indicators Collection

This repository contains a collection of custom trading indicators and scripts, primarily designed for use with TradingView (Pine Script). These tools are tailored for analyzing and trading across various markets, including Stocks, Forex, and Cryptocurrencies.

## Contents

The folder includes a variety of technical analysis indicators, ranging from simple moving averages and momentum oscillators to complex price action and smart money concept (SMC) suites.

## Usage

Most of the text (`.txt`) and pine (`.pine`) files contain Pine Script source code. To use these indicators:
1. Open [TradingView](https://www.tradingview.com/).
2. Navigate to the **Pine Editor** tab at the bottom of the charting interface.
3. Open a new blank indicator workspace.
4. Copy the contents of your desired file and paste it into the editor, replacing any existing code.
5. Click **Add to Chart** or **Save**.
